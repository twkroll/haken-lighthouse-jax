# haken-lighthouse-jax

Modern mathematical and computational reconstruction of Hermann Haken's Lighthouse model for pulse-coupled neural networks, with a JAX-first implementation strategy.

## Project layers

1. **Historical core** — equations and assumptions traceable to Haken's original Lighthouse model.
2. **Mathematical reconstruction** — a precise hybrid dynamical-systems formulation.
3. **Modern extensions** — graph, continuum, delays, noise, plasticity, differentiable approximations.
4. **JAX implementation** — reproducible, vectorized and accelerator-ready numerical realizations.

## Status

Initial theory reconstruction in progress.

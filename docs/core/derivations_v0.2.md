# CORE derivations v0.2

## Purpose

This document turns the v0.1 model definition into explicit analytical reference results. The target is not merely exposition: every boxed relation below is intended to become a numerical or symbolic benchmark for the implementation.

Provenance tags follow `mathematical_core.md`:

- **[H]** historical Haken result/structure;
- **[C]** contemporary reconstruction, especially Coombes (2025/2026);
- **[P]** project derivation/canonicalisation.

The baseline graph model is

\[
\dot\theta_i(t)=S(\psi_i(t)),\qquad
\psi_i(t)=\sum_j w_{ij}a_j(t-\tau_{ij}),
\]

\[
a_i(t)=\sum_{m\in\mathbb Z}\eta(t-T_i^m),
\]

with lifted firing section `theta_i = 2*pi*m` and causal, normalised kernel

\[
\eta(t)=0\ (t<0),\qquad \int_0^\infty \eta(t)\,dt=1.
\]

---

# 1. Periodic kernel generated by a spike train

Define the **undelayed periodic kernel comb**

\[
R_T(t)=\sum_{m\in\mathbb Z}\eta(t-mT).
\tag{D1}
\]

It is `T`-periodic. A common delay `tau` simply shifts it:

\[
P_T(t;\tau)=R_T(t-\tau).
\tag{D2}
\]

Because `eta` is normalised,

\[
\boxed{\int_0^T R_T(s)\,ds=1}
\tag{D3}
\]

for every `T>0`. This identity is the reason the period of the linear Lighthouse model is independent of the detailed synaptic waveform.

## 1.1 Exact alpha-kernel comb [P]

For

\[
\eta_\alpha(t)=\alpha^2 t e^{-\alpha t}H(t),
\]

let

\[
u=t\bmod T\in[0,T),\qquad r=e^{-\alpha T}.
\]

Then

\[
R_T(t)=\alpha^2e^{-\alpha u}
\left[
\frac{u}{1-r}+\frac{Tr}{(1-r)^2}
\right].
\tag{D4}
\]

Derivation: causality reduces the comb to

\[
R_T(t)=\alpha^2e^{-\alpha u}\sum_{n=0}^\infty (u+nT)r^n,
\]

and the geometric sums

\[
\sum_{n\ge0}r^n=\frac1{1-r},\qquad
\sum_{n\ge0}nr^n=\frac{r}{(1-r)^2}
\]

give (D4).

This gives an exact pointwise benchmark for the periodic synaptic waveform, not only an integral benchmark.

## 1.2 Exact hybrid state on the alpha-kernel orbit [C/P]

Use Coombes' state convention

\[
\dot a=-\alpha a+\alpha u,\qquad
\dot u=-\alpha u,
\tag{D5}
\]

with spike jump

\[
u^+=u^-+\alpha,\qquad a^+=a^-.
\tag{D6}
\]

In the periodic stationary state, immediately after a spike,

\[
\boxed{u^+=\frac{\alpha}{1-r}},\qquad
\boxed{a^+=\frac{\alpha^2Tr}{(1-r)^2}}.
\tag{D7}
\]

For `0 <= t < T`,

\[
u(t)=\frac{\alpha e^{-\alpha t}}{1-r},
\]

\[
a(t)=\alpha^2e^{-\alpha t}
\left[
\frac{t}{1-r}+\frac{Tr}{(1-r)^2}
\right]=R_T(t).
\tag{D8}
\]

The v0.1 project state `q=alpha*u` is exactly equivalent: `q^+=q^-+alpha^2`.

# 2. One Lighthouse neuron

## 2.1 Isolated neuron [H/C]

With no recurrent input, `psi=0`, hence

\[
\dot\theta=S(0).
\]

If `S(0)>0`,

\[
\theta(t)=\theta(0)+S(0)t
\]

and the inter-spike interval is

\[
\boxed{T_0=\frac{2\pi}{S(0)}}.
\tag{D9}
\]

If `S(0)=0`, the isolated neuron is silent under the no-reset-below-threshold convention.

For the linear mid-range model

\[
S_L(x)=\gamma x-\Theta,
\]

an isolated neuron fires only in the valid linear regime with `-Theta>0`, and

\[
\boxed{T_0=-\frac{2\pi}{\Theta}}.
\tag{D10}
\]

## 2.2 Constant external drive [P]

If a constant project-level drive `I_0` is included,

\[
\boxed{T(I_0)=\frac{2\pi}{S(I_0)}}
\tag{D11}
\]

provided `S(I_0)>0`. In the linear regime,

\[
\boxed{T(I_0)=\frac{2\pi}{\gamma I_0-\Theta}}.
\tag{D12}
\]

This is the cleanest event-time unit test because it does not involve convolution or network coupling.

## 2.3 Delayed autapse [C/P]

For one neuron with self-weight `w` and delay `tau`, a periodic spike train has

\[
\psi(t)=wR_T(t-\tau).
\]

Existence requires

\[
\boxed{2\pi=\int_0^T S\!\left(wR_T(s-\tau)\right)ds.}
\tag{D13}
\]

Since the integral is over a full period, the existence equation is independent of the delay `tau`; delay can nevertheless change stability.

For the linear model, (D3) gives

\[
2\pi=\gamma w-\Theta T,
\]

hence

\[
\boxed{T=\frac{\gamma w-2\pi}{\Theta}}
\tag{D14}
\]

when the parameters give `T>0` and the orbit remains in the assumed linear operating range.

# 3. General phase-locked ansatz

This is the key extension beyond pure synchrony.

Assume all neurons fire with common period `T` but fixed offsets `phi_i`:

\[
T_i^m=mT+\phi_i.
\tag{D15}
\]

Use the local cycle coordinate of neuron `i`,

\[
t=mT+\phi_i+s,\qquad 0\le s<T.
\]

Then its input is

\[
\psi_i^{\rm PL}(s)
=
\sum_j w_{ij}
R_T\!\left(s+\phi_i-\phi_j-\tau_{ij}\right).
\tag{D16}
\]

Therefore a phase-locked state must satisfy the `N` self-consistency equations

\[
\boxed{
2\pi=
\int_0^T
S\!\left(
\sum_j w_{ij}R_T(s+\phi_i-\phi_j-\tau_{ij})
\right)ds,
\quad i=1,\ldots,N.
}
\tag{D17}
\]

Only relative offsets matter: adding the same constant to all `phi_i` is global time translation. Fixing, for example, `phi_1=0` removes this gauge freedom.

Equation (D17) is the natural nonlinear root problem for phase-locked branches.

## 3.1 Two neurons [P]

Set

\[
\phi_1=0,\qquad \phi_2=\Delta\pmod T.
\]

Then `(T,Delta)` must solve

\[
\boxed{
2\pi=
\int_0^T
S\left[
 w_{11}R_T(s-\tau_{11})
+w_{12}R_T(s-\Delta-\tau_{12})
\right]ds
}
\tag{D18}
\]

and

\[
\boxed{
2\pi=
\int_0^T
S\left[
 w_{21}R_T(s+\Delta-\tau_{21})
+w_{22}R_T(s-\tau_{22})
\right]ds.
}
\tag{D19}
\]

These two scalar equations are the minimal two-cell branch problem.

### Structural degeneracy of the linear model

For `S_L(x)=gamma*x-Theta`, (D3) implies

\[
2\pi=\gamma\sum_jw_{ij}-\Theta T.
\tag{D20}
\]

Thus a common period exists only if the relevant row sums are equal (apart from compensating external drives). If

\[
\sum_jw_{ij}=\Gamma\quad\forall i,
\]

then

\[
\boxed{T=\frac{\gamma\Gamma-2\pi}{\Theta}.}
\tag{D21}
\]

Crucially, the phase offsets and delays drop out of the **existence** equations in the linear model. Therefore phase selection is not encoded by (D20) alone; it must come from admissibility/first-crossing constraints and, especially, stability. For nonlinear `S`, relative pulse overlap inside `S(sum_j ...)` can make (D17) depend nontrivially on the offsets.

# 4. Synchronous N-neuron orbit

Synchrony is the special case

\[
\phi_i=0\quad\forall i,
\]

with common delay `tau_ij=tau` and row sum

\[
W\mathbf 1=\Gamma\mathbf 1.
\tag{D22}
\]

Then

\[
\psi_i(t)=\Gamma R_T(t-\tau),
\]

and the scalar period equation is

\[
\boxed{
F(T)=2\pi-
\int_0^T S\!\left(\Gamma R_T(s-\tau)\right)ds=0.
}
\tag{D23}
\]

This reproduces the contemporary synchrony condition.

## 4.1 Admissibility / no premature firing [P]

A root of (D23) is a candidate periodic orbit. To ensure that the prescribed event at `T` is the first crossing after the previous event, define

\[
A_T(t)=\int_0^tS\!\left(\Gamma R_T(s-\tau)\right)ds.
\]

Require

\[
\boxed{A_T(t)<2\pi\quad\text{for all }0<t<T.}
\tag{D24}
\]

If `S(...)>0` throughout the cycle, (D24) follows automatically from strict monotonicity and `A_T(T)=2*pi`.

This explicit admissibility check should be part of branch continuation and testing, particularly for thresholded `S` where long zero-velocity plateaus can occur.

## 4.2 Exact linear period [H/C]

Using (D3),

\[
2\pi=\gamma\Gamma-\Theta T,
\]

so

\[
\boxed{T=\frac{\gamma\Gamma-2\pi}{\Theta}.}
\tag{D25}
\]

For balance, `Gamma=0` and `Theta<0`,

\[
\boxed{T=\frac{2\pi}{|\Theta|}.}
\tag{D26}
\]

This period is independent of network size, alpha-kernel rate, and common delay, provided the synchronous orbit is admissible.

# 5. Event-time linearisation

Let the synchronous firing times be `mT` and perturb them to

\[
\widetilde T_i^m=mT+\delta T_i^m.
\]

Let

\[
\delta\theta_i(t)=\widetilde\theta_i(t)-\theta(t).
\]

The firing condition

\[
\theta(mT)=\widetilde\theta_i(mT+\delta T_i^m)
\]

gives, to first order,

\[
0=\delta\theta_i(mT)+\dot\theta(T)\delta T_i^m,
\]

hence

\[
\boxed{
\delta T_i^m=-\frac{\delta\theta_i(mT)}{\dot\theta(T)}.
}
\tag{D27}
\]

This relation requires a transversal event,

\[
\boxed{\dot\theta(T)\ne0.}
\tag{D28}
\]

For the linear Lighthouse model with one common delay, define

\[
G_p=\int_0^T\eta'(t-\tau+pT)dt
=\eta(T-\tau+pT)-\eta(-\tau+pT).
\tag{D29}
\]

The spike-section perturbations obey the linear difference equation

\[
\boxed{
\delta\theta_i((m+1)T)-\delta\theta_i(mT)
=
\frac{\gamma}{\dot\theta(T)}
\sum_jw_{ij}\sum_pG_p
\left[
\delta\theta_j((m-p)T)-\delta\theta_i(mT)
\right].
}
\tag{D30}
\]

Periodicity implies

\[
\sum_pG_p=0.
\tag{D31}
\]

Taking

\[
\delta\theta_i(mT)=v_i e^{m\lambda}
\]

and an eigenmode `Wv=w_hat_mu*v` gives the characteristic factor

\[
(e^\lambda-1)\,\mathcal E_\mu(\lambda)=0,
\tag{D32}
\]

with

\[
\boxed{
\mathcal E_\mu(\lambda)
=
\dot\theta(T)-\gamma\widehat w_\mu\,\mathcal G(\lambda),
}
\tag{D33}
\]

\[
\boxed{
\mathcal G(\lambda)=
\frac1T\sum_{n\in\mathbb Z}
\widehat\eta(\omega_n-i\lambda/T)
\exp[-i(\omega_n-i\lambda/T)\tau],
\quad \omega_n=\frac{2\pi n}{T}.
}
\tag{D34}
\]

The factor `e^lambda-1` contains the neutral global time-translation mode. True transverse stability requires all non-neutral roots associated with network modes to satisfy `Re(lambda)<0`.

# 6. Two-neuron mode decomposition

For the symmetric two-cell matrix

\[
W=\begin{pmatrix}
w_s&w_c\\
w_c&w_s
\end{pmatrix},
\tag{D35}
\]

the eigenvectors are

\[
v_+=(1,1)^T,\qquad v_-=(1,-1)^T,
\]

with eigenvalues

\[
\boxed{\widehat w_+=w_s+w_c=\Gamma},
\qquad
\boxed{\widehat w_-=w_s-w_c.}
\tag{D36}
\]

The `+` mode contains the common timing direction. The `-` mode is the leading diagnostic of relative phase stability. Therefore the two-cell synchrony test should evaluate (D33) specifically at `w_hat_minus`.

# 7. Flow + saltation formulation for alpha synapses

For zero delay and the linear response, use

\[
x_i=(\theta_i,a_i,u_i)^T,
\]

\[
\dot x_i=Ax_i+\gamma\sum_jw_{ij}F(x_j)+b,
\]

where

\[
A=
\begin{pmatrix}
0&0&0\\
0&-\alpha&\alpha\\
0&0&-\alpha
\end{pmatrix},
\qquad
F(x)=(a,0,0)^T,
\qquad
b=(-\Theta,0,0)^T.
\tag{D37}
\]

At a spike,

\[
g(\theta,a,u)=(\theta,a,u+\alpha).
\tag{D38}
\]

For a network eigenmode define

\[
\beta=\gamma\widehat w_\mu,
\qquad
DF=
\begin{pmatrix}
0&1&0\\0&0&0\\0&0&0
\end{pmatrix}.
\tag{D39}
\]

The flow matrix over one period is

\[
E_\beta(T)=\exp[(A+\beta DF)T].
\tag{D40}
\]

For `r=exp(-alpha*T)`, this exponential has the exact closed form [P]

\[
\boxed{
E_\beta(T)=
\begin{pmatrix}
1 & \dfrac{\beta(1-r)}{\alpha} &
\dfrac{\beta[1-r(1+\alpha T)]}{\alpha}\\[1.0ex]
0&r&\alpha T r\\
0&0&r
\end{pmatrix}.
}
\tag{D41}
\]

This is an exact matrix-level benchmark for any numerical matrix-exponential implementation.

## 7.1 Saltation matrix

Let the event surface normal be

\[
n=(1,0,0)^T.
\]

Because `Dg=I`, while the jump `u^+-u^-=alpha` changes the vector field by

\[
f^+-f^-=(0,\alpha^2,-\alpha^2)^T,
\]

the saltation formula gives

\[
K=I+\frac{(f^+-f^-)n^T}{n^Tf^-}.
\]

Hence

\[
\boxed{
K(T)=
\begin{pmatrix}
1&0&0\\
\alpha^2/\dot\theta(T)&1&0\\
-\alpha^2/\dot\theta(T)&0&1
\end{pmatrix}.
}
\tag{D42}
\]

The mode monodromy matrix is therefore

\[
\boxed{M_\mu=K(T)E_{\gamma\widehat w_\mu}(T).}
\tag{D43}
\]

The map-based characteristic calculation and the eigenvalues of (D43) must agree in overlapping regimes. This is a primary cross-validation target.

# 8. Slow-synapse characteristic equation

When

\[
\frac{\alpha T}{2\pi}\ll1,
\]

the contemporary analysis gives

\[
\dot\theta(T)=\frac{2\pi}{T}
\]

and for the alpha kernel

\[
\boxed{
\left(1+\frac{\lambda}{\alpha T}\right)^2
=
\frac{\gamma\widehat w_\mu}{2\pi}
\exp\left(-\frac{\lambda\tau}{T}\right).
}
\tag{D44}
\]

For zero delay and real `w_hat_mu`,

\[
\boxed{
\lambda_\pm
=\alpha T\left[-1\pm\sqrt{\frac{\gamma\widehat w_\mu}{2\pi}}\right].
}
\tag{D45}
\]

The square root is understood on the complex plane. If `c=gamma*w_hat_mu/(2*pi)` is real and negative, both roots have real part `-alpha*T`. If `c>=0`, this reduced mode is stable when `c<1` and becomes static at `c=1`.

## 8.1 Delay-induced imaginary-axis condition: normalization check

Set

\[
x=\frac{\omega}{\alpha T},\qquad
y=\frac{\omega\tau}{T},\qquad
c=\frac{\gamma\widehat w_\mu}{2\pi}.
\]

Substitution `lambda=i*omega` directly into (D44) gives

\[
\boxed{1-x^2=c\cos y,\qquad 2x=-c\sin y.}
\tag{D46}
\]

Squaring and adding gives

\[
(1+x^2)^2=c^2,
\]

so a nonzero delay-induced crossing requires the corresponding magnitude condition `|c|>=1`, together with the phase condition from (D46).

### Source erratum note

The current published Coombes PDF has Eq. (28) with the factor `gamma*w_hat_mu/(2*pi)`, but its displayed Eq. (29) prints `2*pi*gamma*w_hat` on the right-hand sides. The latter is not the real/imaginary decomposition of Eq. (28), and the subsequent formulas in the paper return to the `gamma*w_hat/(2*pi)` normalization. CORE therefore treats (D46), derived directly from Eq. (28), as the reference relation.

# 9. What v0.2 establishes

The mathematical validation ladder now has explicit objects at its first four rungs:

1. **single node:** exact free period and constant-drive period;
2. **synapse:** exact alpha periodic waveform and exact periodic hybrid state;
3. **two cells / phase locking:** explicit `(T,Delta)` root equations and symmetric/antisymmetric modes;
4. **N synchrony / stability:** exact period relation, event-time characteristic function, closed-form flow matrix, and saltation matrix.

The next theory step (v0.3) should be nonlinear branch continuation: solve (D17) for phase-locked offsets, derive the Jacobian of the branch equations, and classify fold, symmetry-breaking, grazing, and delay-induced instabilities.

## Frozen first scientific target

The first v0.27 target is hierarchical recovery of two shared Lighthouse network parameters from repeated independently prepared N=3 trials with low-dimensional q=1 preparation variability, Gaussian labelled spike-time noise, and observed MCAR missing labelled spike slots, using no active pulse.

The shared scientific block is

`theta_s = (p, tau_3)`.

The trial-specific preparation block is six-dimensional and gauge-fixed in the zero-mean q=1 subspace:

`z_r = (eta_r, xi_psi,r, xi_q,r) in R^6`,

with each sub-block two-dimensional.

The hierarchical law is

`z_r | lambda ~ iid N(0, Sigma_z(lambda))`,

where

`Sigma_z(lambda) = diag(sigma_phi^2 I_2, sigma_psi^2 I_2, sigma_q^2 I_2)`

and `sigma_a = exp(lambda_a)`. The population-level unknown block is therefore five-dimensional:

`vartheta = (p, tau_3, lambda_phi, lambda_psi, lambda_q)`.

The nominal preparation means are fixed design states in the first target; unknown population means and covariance anisotropy/cross-covariances are deferred.

## Frozen observation model

For a fixed horizon H, labelled spike slots are generated by the frozen deterministic Lighthouse scheduler. Observed timestamps satisfy

`y_rk = F_H,k(theta_s,z_r) + epsilon_rk`,

with iid Gaussian timing noise of known scale `sigma_t`.

Observed masks satisfy an iid MCAR model with known `pi_miss`. Missingness removes the timestamp for a known labelled slot but does not remove the physical spike from the latent trajectory.

Unlabelled spikes, unknown topology, unknown observation clock, and alternative missing-data mechanisms are excluded from the first target.

## Frozen intervention/calibration disposition

The first v0.27 execution is passive: no active pulse, direct subthreshold sensor, pulse calibration inference, or active-design optimization is allowed.

This is a scope decision, not a sufficiency claim. It prevents import of the exploratory legacy v0.24–v0.26 optimized interventions as confirmatory evidence.

## Frozen primary inference route

The primary route is Laplace-approximated marginal maximum likelihood with per-trial Gaussian random effects.

For each trial, the conditional mode minimizes the preregistered joint negative log-density, and the population objective uses the mode value plus one-half log determinant of the trial Hessian.

The primary method may not be replaced post hoc by EM, variational inference, MCMC, another prior, or another objective in the same branch if the preregistered method fails.
